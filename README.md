# # e-plantShopping

## Paradise Nursery

Paradise Nursery is a plant shopping web application that allows users to browse and purchase a variety of houseplants online.

### Features
- Browse houseplants organized into different categories.
- View plant names, images, and prices.
- Add plants to the shopping cart.
- Increase or decrease plant quantities.
- Remove items from the cart.
- View the total number of items and the total cost.
- Navigate between the home, plants, and shopping cart pages.

### Technologies Used
- HTML5
- CSS3
- JavaScript
- React
- Redux Toolkit

### Project Overview
The purpose of this project is to develop a responsive plant shopping application with an interactive product listing and shopping cart. Redux Toolkit is used to manage the shopping cart state and keep item quantities and totals updated.

The application is deployed using GitHub Pages.
